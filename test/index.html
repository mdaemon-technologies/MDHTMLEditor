Editor

Keyboard shortcuts: Ctrl/Cmd+B bold, Ctrl+I italic, Ctrl+U underline, Ctrl+Z/Ctrl+Shift+Z undo/redo, Ctrl+F find & replace.

HTML Output

Type a few blank lines (press Enter on empty lines) between paragraphs, then Refresh: format_empty_lines fills each empty block with <br> so the blank lines survive outside the editor. Round-trip runs setContent(getContent()) — with the flag on, blank lines stay put instead of doubling each time. Every other content path shares that same pair: the change event logs whether its payload matches getContent(), insertContent() / the Templates dropdown run the import half (paste this panel's HTML into the box below and click Insert content), and the toolbar's Source code and Preview buttons show the same output getContent() returns.

Stored template import

The Templates dropdown carries the two shapes a stored email template actually arrives in. Pretty-printed Status is one stored as authored — real newlines and tabs between the blocks, including inside the <ul> — and inserts as two bullets, not four, with no literal tabs and no <br> on the &nbsp; line. Wrapped template is one swaddled in container <div>s with placeholder <a href=""> links: a block cannot contain a block in the schema, so each wrapper used to be left behind as an empty paragraph (four blank lines above the content) and every empty-href anchor was deleted down to bare text. It now inserts flush with no blank lines, keeps all three links, and carries the wrapper's Georgia/10pt onto every line instead of stranding it on a blank. The javascript: target at the end must still arrive as plain text. Long wrapped body is the same shape at full scale — five nested wrappers, eight placeholder links, four &nbsp; spacers and a run of unmatched closing tags — and should insert as nine lines with all eight <a> elements intact. Check the HTML Output panel for all of it.

Pasted lists

Copy a numbered or lettered list out of Word, Outlook, Google Docs or a web page and paste it into the body. It lands at the editor's own list indent — the source document's margin-left/text-indent is dropped, so the list is not pushed a level further right than one built with the toolbar — and a lettered (A, B, C) or roman (i, ii, iii) list keeps its numbering instead of being renumbered 1, 2, 3. Check the HTML Output panel for the <ol type="A"> that carries it. Increase/Decrease indent (and Tab / Shift+Tab) then move the items: nesting where an item can nest, otherwise a margin-left on the <li> so the number travels with the text. The Templates dropdown's Numbered list styles entry loads the same cases without a clipboard.

Paste Markdown

Link edges

Paste https://example.com (or user@example.com) into the editor and keep typing without pressing Enter: the URL is linked, and the words typed after it stay plain text. The same holds after pasting HTML that ends in a link, and after inserting a link from the Link dialog with nothing selected. Clicking at the end of an existing link and typing still extends it, and selecting a link's text and retyping it keeps the link. Check the HTML Output panel: the </a> should close right after the URL.

Pasting a URL over selected text within a paragraph links that text. Press Ctrl+A and paste a URL instead: the content is replaced by the linked URL. Clicking a link places the caret and does not open the link; the Link button then edits that link in place.

Code sample

Loads three lines separated by <br> (one paragraph, as Shift+Enter or an email signature makes) with the caret on the last one. Click the Code sample toolbar button or press Ctrl+Alt+C: only the caret's line becomes a code block, and the lines above stay text. A selection across several of the lines becomes one code block.

Image resizing

Loads two images: one at its own size, and one stored stretched (width="300" height="80") that the editor now shows as a mail client would. Click an image and drag a handle: corners keep the aspect ratio (hold Shift to stretch), sides change one dimension, and Escape puts it back. The HTML Output panel shows the new width/height, and the Event Log shows objectresizestart/objectresized. Toggle read-only to see the handles disappear.

Custom Toolbar Buttons

These buttons were added via editor.ui.registry.addButton() in the setup callback and included in the toolbar string.

setup: (ed) => { // Text-label button ed.ui.registry.addButton('wordcount', { text: '💬 Words', tooltip: 'Show word count', onAction: () => { /* ... */ }, }); // Icon (SVG data-URI) button ed.ui.registry.addButton('timestamp', { icon: 'data:image/svg+xml,...', tooltip: 'Insert timestamp', onAction: () => { /* ... */ }, }); // Toggle button with active state ed.ui.registry.addButton('markpen', { text: '🖍️', tooltip: 'Toggle mark pen', onSetup: (api) => { api.setActive(false); }, onAction: (api) => { api.setActive(!api.isActive()); }, }); } // toolbar must list the names: toolbar: '... wordcount timestamp markpen'
